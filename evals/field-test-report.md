# 사용자 실사용 테스트 검토

확인일: 2026-10-29. 이 문서는 사용자가 제공한 실사용 결과의 문제를 요약한다. 개인 사진, 대화 식별자, 대화 전문은 재배포하지 않는다.

## 기존 링크 방식: 실패

0.1.3까지 배포된 기간에 사용자가 일반 ChatGPT에 저장소 홈 링크와 외관 사진을 제공했다. 실행 시점에 읽힌 파일·버전은 확인되지 않아 특정 Skill 버전의 정식 호출 테스트로 간주하지 않는다.

확인한 문제:

- 실제로 프로젝트 기준을 읽었는지 확인되지 않는데 프로젝트 지침을 참고했다고 표시했다.
- 내부 결속·접착·낙장을 확인하지 못한 상태에서 제본 등급을 부여했다.
- 사용자가 찢김이라고 정정하자 크기와 제본 영향을 확인하지 않고 등급을 낮췄다.
- 일반적인 알라딘 등급 검색을 수행한 기록은 사용자 피드백에서 확인됐다. 특정 개인 블로그의 열람·판정 반영 여부는 확인되지 않는다.

판단: 프로젝트 지침을 적용하는 사용자 흐름에 실패가 있었다. 등급 숫자만 맞는지를 평가한 시험이 아니며 사진 판독 정확도 백분율을 산출할 수 없다.

## 0.1.4 보완

- 저장소 홈 README 본문에 지침과 기준을 직접 포함해 별도 파일 클릭에 대한 의존을 줄였다.
- 프로젝트 규칙을 이미 읽은 상태의 일반 기준 검색과 개인 블로그 대체를 금지하도록 안내했다.
- 실제로 지침을 읽고 적용했을 때의 적용 지침 표시와 규칙 ID를 추가했다.
- 외관만 있는 제본 판정, 크기·제본 영향이 미확인인 책등 찢김의 단정을 금지하도록 보완했다.
- 관련 정형 시나리오를 추가했다. 수정된 지침을 사용한 일반 ChatGPT 재시험은 아직 미실행이다.

README 안의 지침은 호스트가 내용을 읽고 따르는 경우에 적용된다. 링크 공유만으로 스킬 설치·호출을 강제하거나 성공을 증명할 수는 없다. 결과의 적용 지침 표시도 실제 호출 로그를 대신하지 않는다.
