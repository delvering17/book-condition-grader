# ISBN으로 알라딘에 팔기 조회

## ISBN 확인

뒷표지 사진이나 영상의 뒷면 장면에서 바코드 옆에 인쇄된 ISBN을 먼저 읽는다. 이미 선명하게 보이면 바코드 사진을 다시 요구하지 않는다. 가림·흐림·잘림 때문에 번호를 읽을 수 없을 때만 바코드 근접 사진이나 ISBN 숫자 입력을 요청한다. 품질 판독은 ISBN 확인과 무관하게 계속한다.

978/979로 시작하는 ISBN-13 또는 구판 ISBN-10을 사용한다. 바코드 옆의 별도 5자리 부가기호, 가격, 알라딘 관리용 스티커 번호를 ISBN에 붙이지 않는다. 세트와 낱권 번호가 함께 있거나 여러 권이면 사진 속 대상과 연결되는 번호를 확인한다. 책 제목만으로 ISBN을 추측해 채우지 않는다.

공백·하이픈과 ISBN 표기를 정리하고 체크 숫자를 검증한다. 잘못 읽은 번호를 맞추려고 숫자를 고치거나 누락 자리를 생성하지 않는다. 체크 숫자 통과도 사진에서 정확히 읽었다는 증거는 아니므로 애매한 글자는 사용자에게 확인한다.

ISBN-13은 전체 13자리에 왼쪽부터 1·3을 번갈아 곱한 합이 10의 배수여야 한다. ISBN-10은 마지막 X를 10으로 보고 왼쪽부터 10~1을 곱한 합이 11의 배수여야 한다. 유효한 ISBN-10은 마지막 자리를 빼고 978을 앞에 붙인 뒤 ISBN-13 체크 숫자를 다시 계산한다. 로컬 파일 실행이 가능한 환경에서는 `scripts/isbn_lookup.py`를 이 검증과 URL 생성에 사용할 수 있다. 이 보조 스크립트는 네트워크 조회나 이미지 판독을 하지 않는다.

## 정확한 URL로 읽기 전용 조회

유효하고 식별이 명확한 ISBN을 얻으면 다음 주소의 `{ISBN13}`만 숫자로 치환해 링크를 만든다.

```text
https://www.aladin.co.kr/shop/usedshop/wc2b_search.aspx?ActionType=1&SearchTarget=All&KeyWord={ISBN13}
```

현재 환경의 웹 열람 도구로 이 주소를 읽기 전용으로 요청한다. 웹 열람으로 결과를 읽지 못해도 실행 도구가 읽기 전용 HTTP 요청을 지원하면 같은 URL을 확인할 수 있다. 도구가 제공하지 않는 네트워크 기능을 사용할 수 있다고 가정하지 않는다. 이 조회는 ISBN별 매입 상태 확인이며 품질 기준을 다른 웹 검색으로 대체하는 절차가 아니다. 개인 블로그나 일반 상품 구매 페이지에서 매입 여부를 추정하지 않는다. 로그인·장바구니 추가·판매 신청은 수행하지 않는다.

해당 ISBN과 일치하는 **상품 결과 영역**에서 제목·판본·출판사 등 대상이 맞는지 확인하고 그 상품에 붙은 매입 상태를 읽는다. 페이지 아래의 일반 매입불가 안내를 해당 상품의 상태로 오인하지 않는다. 단순히 페이지에 ‘매입불가’라는 단어가 있다는 이유로 분류하지 않는다.

| 응답 상태 | 결과에 쓸 매입 상태 |
| --- | --- |
| ISBN 일치 상품에 매입 안내·등급별 매입가·팔기 추가 동작이 표시됨 | 조회상 매입 가능 |
| ISBN 일치 상품에 매입불가라고 명시됨 | 현재 매입불가 |
| 페이지가 정상 열리고 해당 ISBN의 검색 결과 없음이 명시됨 | 검색 결과 없음 |
| 링크 열람 실패·차단·로그인 필요·검색창만 표시·매입 상태를 확인할 수 없을 만큼 결과 누락 | 실시간 확인 못함 |
| 상품의 ISBN·판본이 다르거나 여러 결과 중 대상이 불명확함 | 상품 확인 필요 |
| ISBN이 없거나 불명확·검증 실패 | ISBN 확인 필요 |

응답을 실제로 읽은 경우 조회 시각을 한국 시간으로 기록한다. 읽지 못했으면 조회 완료 시각이나 매입 상태를 만들어내지 않고 링크는 제공한다. ISBN이 확인되지 않았으면 잘못된 번호를 넣은 링크 대신 [알라딘 팔기 검색](https://www.aladin.co.kr/shop/usedshop/wc2b_search.aspx)을 제공하고 추가 확인에 ISBN 요청을 넣는다.

결과에는 짧은 `[팔기 조회]({조회_URL})` 링크를 항상 둔다. 검색 주소 생성과 실제 응답 확인은 구분한다. 품질상 매입불가이면 상품 조회에 매입 가능으로 나와도 실제 판매 가능을 보장하지 않는다. 재고·상태·판본에 따라 최종 매입 여부가 달라진다.

## 등급별 매입 예상가

일치 상품의 결과에서 **매입가 최상·상·중** 헤더와 같은 행의 금액을 대응시켜 읽는다. 같은 표의 ‘정가’는 매입가가 아니며 일반 상품 판매가·중고 판매가와도 구분한다. 금액·원 단위·범위는 실제 표시대로 옮기고 조회 시각을 함께 남긴다. 서로 다른 상품이나 다른 조회 시점의 가격을 합치지 않는다.

결과 템플릿의 짧은 가격표에 세 등급의 조회 금액과 ‘이번 예상등급 기준’ 금액을 표시한다. 최종 예상등급이 상이면 상 매입가를 연결하고 잠정등급이면 ‘상 가정·잠정’이라고 한정한다. 판정 보류나 등급 범위만 있으면 세 등급 가격을 참고로 보여주되 적용 금액은 산정 보류다. 품질상 매입불가 또는 조회상 현재 매입불가이면 적용 금액을 제시하지 않는다.

조회 실패·ISBN 미확인·상품 불일치·가격 누락이면 해당 가격은 `확인 못함`으로 둔다. 특히 상 매입가가 빠졌다고 최상·중 가격을 평균 내거나 다른 등급의 금액을 사용하지 않는다. ‘-’나 공란을 0원으로 바꾸지 않고, 정가의 일정 비율로 추정하지 않는다. 페이지가 금액을 명시적으로 0원으로 표시했다면 그 표시만 전달하고 매입 가능 여부는 별도로 확인한다. 조회 가격은 최종 지급액을 보장하지 않는다.

## 조회 주소와 ISBN 기준 출처

2026-10-29 기준: [알라딘 팔기 검색](https://www.aladin.co.kr/shop/usedshop/wc2b_search.aspx)의 GET 폼은 `ActionType=1`, `SearchTarget=All`, `KeyWord`를 사용한다. 웹 페이지를 읽을 수 있는 도구에서 같은 주소로 조회한다.

ISBN 검증 출처: [International ISBN Agency](https://www.isbn-international.org/content/what-isbn/10), [미국 ISBN 기관 FAQ](https://www.isbn.org/faqs_general_questions), [ISBN 변환 안내](https://www.isbn-international.org/content/isbn-calculator). ISBN·링크 처리와 매입 상태 요약은 프로젝트의 추가 기능이며 알라딘의 공식 품질등급 규칙을 변경하지 않는다.
