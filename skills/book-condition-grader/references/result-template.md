# 간결한 결과 템플릿

아래 순서·제목·표 열을 유지하고 중괄호 내용을 실제 자료로 치환한다. 이미지·ISBN·조회 응답이 없으면 그 자리를 확인 불가·확인 필요로 표시한다. 품질 판정이 보류돼도 ISBN을 읽을 수 있으면 팔기 조회 링크를 제공한다. 원문 URL을 길게 노출하지 않고 `팔기 조회` 링크로 표시한다.

적용 지침 줄은 지침을 실제로 읽은 경우에만 사용한다. 기준을 읽지 못했다면 대신 `지침 확인: 읽기 실패`로 표시하고 예상등급을 보류한다. 이는 설치·실제 스킬 호출의 증거가 아니다.

```markdown
적용 지침: Book Condition Grader · 기준 확인일 2026-10-29

### 중고책 예상 품질등급

**예상등급: {등급과 잠정 범위 또는 판정 보류}**
**알라딘 매입: {조회상 매입 가능 / 현재 매입불가 / 검색 결과 없음 / 실시간 확인 못함 / 상품 확인 필요 / ISBN 확인 필요}** · [팔기 조회]({조회 URL 또는 ISBN 미확인 시 기본 검색 URL})
ISBN: {번호와 출처 또는 확인 불가} · 조회: {실제 조회 시각 또는 미조회}

**조회된 매입 예상가**

| 최상 | 상 | 중 | 이번 예상등급 기준 |
| --- | --- | --- | --- |
| {최상 매입가 또는 확인 못함} | {상 매입가 또는 확인 못함} | {중 매입가 또는 확인 못함} | {해당 등급 금액·잠정 여부 또는 산정 보류/매입불가/확인 못함} |

**판정 근거**

| 검사 항목 | 확인된 상태 | 예상등급 |
| --- | --- | --- |
| {부위} | {사진 번호·관찰 또는 사용자 확인·규칙 ID} | {부분등급 또는 확인 불가} |

**추가 확인:** {필요한 사진·질문만 짧게. 없으면 현재 결론에 필요한 추가 확인 없음}

**종합 의견:** {가장 낮은 확인 등급을 적용한 이유와 미확인 범위. 필요한 별도 매입불가 사유 포함}

**주의사항:** AI 예상 결과이며, 실제 매입 여부와 최종등급은 알라딘에서 결정합니다. [공식 기준](https://www.aladin.co.kr/shop/usedshop/wc2b_sales.aspx?tab=3)
```

검사 행은 실제 사진에 맞게 묶고 불필요하게 반복하지 않는다. 내부·제본을 확인하지 못했다면 반드시 확인 불가로 남긴다. 추가 확인과 종합 의견은 각각 한두 문장으로 작성하되 필요한 확인 사항은 생략하지 않는다. 매입 링크가 생성됐다는 사실만으로 조회상 매입 가능이라고 쓰지 않는다. 등급을 바꾸는 결정적인 손상이 있으면 그 기준과 단위를 표에 남긴다.

매입 예상가 표는 품질 검사표와 구분하고, 일치 상품의 ‘매입가 최상·상·중’에 실제로 표시된 값만 넣는다. 정가·판매가·다른 상품 가격을 넣지 않는다. 예상등급이 잠정 상이면 상 금액에 ‘상 가정·잠정’을 붙인다. 등급이 보류이거나 범위로만 제시됐으면 하나의 금액을 선택하지 않는다. 품질상 또는 조회상 매입불가이면 적용 금액은 산정하지 않으며, 조회된 등급별 금액은 참고값임을 표시한다. 없는 금액을 0원·평균·정가 비율로 채우지 않는다.
