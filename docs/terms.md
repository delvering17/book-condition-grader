# 이용 안내

적용 버전: 0.2.0 · 작성일: 2026-10-29

Book Condition Grader는 사용자가 제공한 책 사진과 설명을 바탕으로 참고용 예상 품질등급을 안내한다. 알라딘 또는 OpenAI의 공식 감정·제휴 서비스가 아니며, 알라딘의 매입 승인·가격·최종등급을 보장하지 않는다.

촬영 범위와 화질, AI의 오인, 기준 변경에 따라 결과가 달라질 수 있다. 미확인 부분은 확인 불가 또는 판정 보류로 표시한다. 실물 상태 확인과 최종 거래 판단은 해당 거래 절차를 따른다. 본 도구는 판매 신청·배송·결제를 수행하지 않는다.

ISBN으로 알라딘 공식 팔기 검색을 읽기 전용으로 조회하고 직접 확인할 링크를 제공할 수 있다. 링크 생성은 매입 확인 완료를 뜻하지 않는다. 조회 시점의 상품 매입 상태와 사진에서 본 물리적 품질은 별도로 표시하며 재고·판본·실물 상태에 따라 실제 매입 결과가 달라질 수 있다.

사용자는 업로드할 권한이 있는 사진과 자료를 제공한다. 코드와 자체 작성 문서의 이용·배포 조건은 저장소의 [MIT License](../LICENSE)를 따른다. 제3자의 상표와 문서 권리는 해당 권리자에게 있다. ChatGPT/Codex와 GitHub 사용에는 각 서비스의 정책이 별도로 적용된다.
