# 개인정보 처리 안내

적용 버전: 0.1.0 · 작성일: 2026-10-29

Book Condition Grader는 사진 판독 지침과 참조 문서로 구성된 오픈소스 Skill이다. 프로젝트가 운영하는 서버·데이터베이스·로그·분석 도구는 없으며, 프로젝트가 사용자의 사진이나 대화를 수집·전송·보관하지 않는다. 별도 회원가입이나 API 키도 요청하지 않는다.

사진과 대화는 사용자가 선택한 ChatGPT/Codex 환경에서 처리된다. 이름·필기·연락처 등 사진에 보이는 정보도 그 입력에 포함될 수 있다. 해당 서비스의 수신자, 보관 기간, 학습 사용 여부, 삭제·데이터 제어는 이용 중인 서비스·계정·워크스페이스 정책에 따른다. 이 Skill은 그 정책을 변경하거나 보관 기간·삭제를 보장하지 않는다. 필요 없는 개인정보는 사진에서 가린 후 업로드한다.

외부 사이트를 자동 호출하거나 사진을 알라딘에 보내지 않는다. 결과에 제공하는 공식 출처 링크를 사용자가 열면 해당 사이트의 정책이 적용된다.

GitHub에 이슈를 남기면 작성 내용·첨부 사진이 GitHub에 공개될 수 있다. 사진이나 개인정보 없이 재현 절차를 먼저 제공한다. 해당 이슈의 수정·삭제는 GitHub의 기능과 정책을 따른다. 프로젝트는 사용자의 대화나 사진에 접근해 삭제할 권한이 없으므로 대화 기록 관리는 해당 서비스의 데이터 제어를 이용한다.

문의: [프로젝트 Issues](https://github.com/delvering17/book-condition-grader/issues). 민감한 정보나 인증정보를 공개 이슈에 기재하지 않는다.
