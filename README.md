# 중고책 품질등급 판독기

**ChatGPT에 책 사진 또는 영상을 첨부하고 위 링크만 보내세요.** 영상은 내용을 읽을 수 있는 환경에서 사용할 수 있습니다. 확인한 장면을 알라딘 공개 기준과 대조해 예상 품질등급과 추가로 확인할 부분을 안내합니다. 첨부 없이 링크만 보내면 촬영할 부분부터 안내하도록 구성했습니다.

## 책 사진은 이렇게 찍으세요

책을 덮은 상태에서 **앞·뒤·위·아래·양옆, 외관 6장**을 찍는 것을 권장합니다. 책 전체와 모서리가 잘리지 않게 찍어 주세요.

| 사진 | 찍을 부분 | 이렇게 보이게 찍으세요 |
| --- | --- | --- |
| 1 | 앞표지 | 책 앞면 전체 |
| 2 | 뒤표지 | 책 뒷면 전체 |
| 3 | 위쪽 | 책을 덮었을 때 위에서 보이는 종이 단면 |
| 4 | 아래쪽 | 책을 덮었을 때 아래에서 보이는 종이 단면 |
| 5 | 옆면 — 책등 | 제목이 적힌 좁은 면 |
| 6 | 반대쪽 옆면 | 책등 반대편의 종이 단면 |

**이 6장은 책의 겉모습을 확인하는 사진입니다.** 책 속 필기·얼룩이나 페이지가 떨어지는 상태까지 확인하려면 책을 펼친 사진도 추가해 주세요. 처음·중간·끝부분과 손상된 페이지를 보여주면 도움이 됩니다.

- 밝은 곳에서 흔들리지 않게 찍어 주세요.
- 찢김이나 얼룩은 가까이 찍고, 크기가 애매하면 옆에 자를 놓아 주세요.
- 필기·얼룩이 있는 쪽은 사진과 함께 전체 몇 쪽인지 알려 주세요.
- 원래 있던 겉표지나 부속물이 빠졌다면 함께 알려 주세요.

**사진 한 장부터 시작해도 됩니다.** 6장을 모두 준비해야만 사용할 수 있는 것은 아닙니다. 보이지 않는 부분은 확인 불가로 남기고 필요한 사진을 추가로 안내합니다.

## 영상은 이렇게 찍으세요

사진 대신 영상으로 앞·뒤·위·아래·양옆을 차례로 보여줘도 됩니다. **각 부위를 보여줄 때마다 최소 2초씩 멈춰 촬영해 주세요.**

- 책과 카메라를 고정하고, 화면이 선명해진 뒤 같은 부위를 최소 2초 동안 보여주세요.
- 한 면을 보여준 다음 천천히 다음 면으로 돌려 주세요.
- 책 속은 처음·중간·끝부분을 펼쳐 보여주고, 각 펼친 면에서도 최소 2초씩 머물러 주세요.
- 찢김·얼룩·필기가 있는 부분은 가까이서 최소 2초씩 더 보여주세요. 크기가 애매하면 자를 함께 놓아 주세요.

페이지를 빠르게 넘기기만 하면 필기나 얼룩을 놓칠 수 있습니다. 영상 전체를 읽을 수 없는 환경에서는 **멈춰 찍은 주요 장면을 캡처해 사진으로 올려 주세요.**

## 사용 순서

1. ChatGPT 새 대화에 책 사진 또는 영상을 첨부합니다.
2. 맨 위 코드블록의 저장소 링크를 복사해 보냅니다.
3. 예상등급과 판정 근거를 확인하고, 추가 사진을 요청하면 이어서 올립니다.

결과는 **최상·상·중·매입불가**로 안내하며, 근거가 부족하면 **판정 보류**로 표시합니다. [결과 예시 보기](docs/grading-example.md)

링크와 첨부 내용을 읽을 수 있는 환경이 필요합니다. 링크가 열리지 않을 때의 사용 방법은 [설치·파일 첨부 안내](docs/installation-and-release.md)를 참고하세요.

## 알아두세요

알라딘과 제휴한 공식 감정 서비스가 아닌 AI 예상 도구입니다. 실제 매입 여부와 최종등급은 알라딘에서 결정합니다. 외관 6장이 있어도 책 내부 전체나 재고·ISBN에 따른 매입 여부까지 확인되는 것은 아닙니다.

실제 사진·영상 판독과 일반 ChatGPT에서의 링크 사용은 아직 검증 전입니다. 자세한 범위는 [검증 현황](evals/validation-report.md)에 정리했습니다.
